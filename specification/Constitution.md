Create an app that reads a fixed input text and warps it around the luminance info of  an input image, video or live webcam feed. The text can be wrapped inside or outside. The input source has input luminance adjustement along invert controls to adjust the image realtime.

The system have webcam, video and image inputs. the image processing over the source should be visible in the source preview. The output can be saved as png or prores file via this project: https://github.com/OlivierEstevez/ProRes-WASM-encoder/tree/master
The UI is based on the css library https://github.com/letieu/terminal.css. the UI must follow the rules of this project https://github.com/srcphag/TextureMosaic

Start to develop for localhost. The app the will be prepared to be deployed in netlify after the local development.
